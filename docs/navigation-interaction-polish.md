# 地图常显、关闭评分与键盘避让

## 地图加载与生命周期

- 页面订阅到配置后自动初始化地图，不再要求点击“同意并加载地图”。首次启动不设置示例导航终点。
- 高德地图初始化与系统定位授权分开：地图先显示，取当前位置时仍通过鸿蒙系统申请定位权限。拒绝定位或定位失败不会主动关闭已就绪的地图。
- 停止导航或到达后保留同一地图实例，停止 GPS、语音和导航监听，清除路线覆盖物；再次定位或规划时复用地图。
- “首页/我的”切换不卸载原生地图。原生地图视图实际移除或页面销毁时完整释放资源。
- 地图初始化失败保留重试入口，不自动循环重试；停止后的旧 SDK 回调和迟到的授权结果不能启动下一条路线。

## 不展示评分

共享页面和状态不再生成评分卡，也不自动提交好评。鸿蒙所有 `navigation.submit` 请求均附加
`client_capabilities.supports_feedback=false`，包括普通文本、修改路线和候选确认。

配套 navi-claw 返回 `feedback_required=false`，正常保存任务与会话，且不为该请求生成等待评分的训练记录。
此能力按当前请求生效，不改变同一后端上 Android 客户端的既有规则。
只安装新 App 即可隐藏评分界面；要停止后端创建待评分记录，还需更新后端并重启实际服务进程。

## 输入法避让

宿主使用 ArkUI 的 `KeyboardAvoidMode.RESIZE`，移除键盘区域的 `expandSafeArea`。
Kuikly 根据宿主可视高度更新根布局，底部输入框、发送按钮及导航面板随键盘弹出上移，收起后恢复。
不重复叠加 Kotlin 键盘高度偏移，不为键盘开关重新创建地图。

## 构建与真机复测

在 App 目录执行 `powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\build-harmony.ps1`，
输出 `artifacts/harmony/navi-harmony-navigation-signed.hap`。
后端在 `navi-claw` 目录执行 `pnpm check`、`pnpm test:protocol`、`pnpm build`，更新部署并重启服务。

真机验收：

1. 冷启动不点击任何地图加载按钮，地图应自动显示；首次系统定位授权仍可能出现。
2. 拒绝定位后仍能浏览地图；授权并重试后可取得当前位置。
3. 规划、开始、停止、到达以及“首页/我的”往返后，地图仍显示；停止后再次输入新目的地能重新规划。
4. 导航任务、候选确认和到达后都不显示评分，也不自动提交评分。
5. 首页点击文本框，输入法弹出时输入框和发送按钮在键盘上方；收起后恢复原位。登录、注册输入框一并复测。
6. 横屏、小屏幕、不同输入法及浮动键盘需要单独视觉检查；编译及静态检查不能代替真机验收。
